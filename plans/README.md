# Plans

New design notes and implementation plans go here as `YYYYMMDD_<name>.md`.

This repository is public: write plans without real addresses, usernames, hostnames, key
aliases or tokens (see `AGENTS.md`). Plans written before the project moved to this
repository (up to 2026-10) are kept privately; the code and docs still cite some of them as
`plans/2026…` for provenance. The design reference is [docs/DESIGN.md](../docs/DESIGN.md).
