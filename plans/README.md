# Plans

New design notes and implementation plans go here as `YYYYMMDD_<name>.md`.

This repository is public: write plans without real addresses, usernames, hostnames, key
aliases or tokens (see `AGENTS.md`). Design notes written before this repository existed
(up to 2026-10) are not published; the code and docs cite them as "pre-split design notes".
The design reference is [docs/DESIGN.md](../docs/DESIGN.md).
