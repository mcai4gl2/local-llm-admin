## ComfyUI Qwen-Image-2.1-Turbo qualification

### Problem / Goal
- Serve official Qwen-Image-2.1-Turbo (int8 safetensors primary, Q4_K_M GGUF secondary) from the existing ComfyUI install, through the admin's exclusive engine control, then restore MLX.
- No admin UI, MFLUX, or benchmark matrix. Live engine switches were in the approved plan.

### Problems Encountered
- Installed workflow templates (json 0.1.96) lacked the turbo templates. Updated the templates packages in the ComfyUI venv to 0.1.129 / meta 0.11.103; the 0.37.0 checkout already had `QwenImage21` and was not upgraded.
- `ComfyUI-GGUF` cloned into `app/custom_nodes` did not load. The launcher sets `--base-directory`, so custom nodes are read from `/Volumes/Models/comfyui/custom_nodes`. Moved the checkout there and restarted ComfyUI through the admin; `UnetLoaderGGUF` then appeared.
- The first image-edit API prompt ignored the reference. `TextEncodeQwenImage21`'s autogrow input must be passed as `images.image_1`, not `image_1` or a nested `images` object. After that, the edit kept the subject and changed the background.
- The template's edit CFG of 8 washed the subject out on this prompt. CFG 2 kept the source text readable. Recorded as a quality note, not a template change.

### Key Design Decisions
- Weight files were saved under the stock template names (underscores) so the shipped turbo workflows resolve without edits. SHA256 was checked against the source repo sums, not the local filenames.
- Prompt-enhancer encoders were not downloaded. Smoke graphs used the template sampler chain with the enhancer switch off.
- Engine changes went through the admin `/api/engine` jobs so exclusivity and resident-service restore stayed on the admin path.

### Solution / Implementation
- Read-only preflight, templates package update, resumable weight download, GGUF custom node, admin switch to ComfyUI, API smoke tests, admin switch back to the previously selected MLX model.
- Host environment records and `host/README.md` now note the base-directory custom-node path and the recorded GGUF node.

### Results
- SHA256 of all four weight files matched the repo `SHA256SUMS`.
- int8 1024: 62.8 s cold, 46.1 s warm (~5.3 s/it). int8 2048: 218.8 s (~25.9 s/it). GGUF Q4_K_M 1024: 52.9–56.5 s (~6.2–6.4 s/it). Single-reference edit: 113–154 s.
- Output images were coherent. System memory pressure after the runs was about 95% free.
- Admin jobs for ComfyUI start, stop, and MLX restore all succeeded. The previously running resident services were listening again; ComfyUI was not.
- Private-pattern leak scan: see the session note after this entry was written.
- pytest/ruff/mypy not run: no application code changed.
