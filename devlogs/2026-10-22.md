## M10 follow-ups: regex timeout and choice grader

### Problem/Goal
A pathological custom regex (`a?`x25 + `a`x25) passed the import check and held the GIL for the whole stdlib `re` match, freezing the admin despite `asyncio.to_thread`. The choice grader also graded "Answer: c\nBecause..." and "Answer Is B" as no answer.

### Solution/Implementation
Regex grader and import-time compile use the `regex` package (V0): per-match timeout `REGEX_TIMEOUT_S` = 1 s with `concurrent=True` (GIL released); a timeout grades 0 with "regex timed out after 1 s". Choice grader: keywords (answer, choice, is, it's) case-insensitive, multiline end-of-line for a lone lowercase letter. README, DESIGN and comments corrected.

### Results
New tests failed first (RED), now pass; a ticker's max gap stays under 0.3 s while a timing-out grade runs in a thread.

## Token usage Task 0: counter checks on the Mac

### Problem/Goal
Confirm the counter semantics the token rollup depends on (approved read-only checks plus a
live Strata check). Strata was the running engine, so MLX was checked from its logs and its
installed source, not with live prompts.

### Solution/Implementation
- MLX (mlx-vlm 0.7.3 source on the Mac): `total_prompt_tokens = reused_prefix_len +
  input_ids.size`, and `Prefill completed prompt_tokens=` logs that total. Cached tokens are
  part of input. The live log (30,185 request lines) has no prefill with `cached_tokens > 0`
  yet, so no live example exists.
- Strata (server source and live `/metrics`): history and `totals` are updated together in
  one `finally` for every finish (`stop`, `length`, `cancel`, `disconnect`, `error`);
  `prompt_tokens` includes `reused` (a cancelled prompt read counts reused + read);
  `totals.since` is `time.time()` at process start. History is a `deque(maxlen=500)`, but
  `/metrics` lists only the newest 12 unless called as `/metrics?requests=all`;
  `requests_kept` is just the listed count. The list is newest *finished* first while
  `time` is the start, so with parallel slots start times are not in list order.
- Live: one short request and one streamed request cut off by the client. Both were listed
  (`length`, `disconnect` with 210 output tokens), and the records add up to `totals`
  exactly (3 requests, 177 prompt, 293 output tokens).
- Fix in `strata_usage.py`: poll `/metrics?requests=all`; take the first
  `totals.requests − last count` records as new instead of comparing start times (which
  would have turned a late-finishing parallel request into a gap row); the state keeps the
  poll time for gap rows.
- Fixture `tests/fixtures/strata/metrics-requests-all.json`: the live request records and
  totals only (numbers and finish reasons).

### Results
`strata_usage.py` at 100% coverage; the live reading run through `strata_rows` gives the
same totals as Strata and a second identical reading adds nothing. ruff and mypy clean.

### Files Modified
- `src/local_llm_admin/strata_usage.py`, `tests/test_strata_usage.py`,
  `tests/fixtures/strata/metrics-requests-all.json` (new), `docs/DESIGN.md`,
  `plans/20261022_token-usage.md`

## Strata: final /metrics reading at stop

### Problem/Goal
Requests a Strata process finished after the admin's last poll were lost when it stopped
(at most one tick of usage).

### Solution/Implementation
- `host/strata/bin/strata stop` saves `/metrics?requests=all` to
  `run/metrics-final-<pid>.json` before SIGTERM: `curl --max-time 3 --max-filesize 8 MiB`,
  the API key in curl's stdin config (never argv), mode 600, kept only if it starts with
  `{`, never blocks the stop.
- `StrataUsage` keeps its cursor per process (`kv strata_usage = {repr(since): state}`,
  newest 8) and, while the drive is mounted, reads up to 4 final files per tick (oldest
  first, at most 8 MiB each), adds their new rows, then deletes them. Bad files are dropped.
  An old process's final reading counts once even after a newer process was polled, and
  the same reading twice adds nothing.

### Results
Host tests (zsh against a fake server and curl) and admin tests pass; full suite 2108 passed,
coverage 98.11%; `strata_usage.py` 100%; ruff and mypy clean. Not deployed: the wrapper
needs `ops/deploy-host.sh --apply`, the admin `ops/deploy-mac.sh`, both with approval.

### Files Modified
- `host/strata/bin/strata`, `host/strata/README.md`
- `src/local_llm_admin/strata_usage.py`, `tests/test_strata_usage.py`, `tests/test_host_strata.py`
- `docs/DESIGN.md`

## Lessons Learned
Under `set -o pipefail`, `{ [[ -n $key ]] && print ...; } | curl` fails when there is no
key; write the guard as `[[ -z $key ]] || print ...`.
